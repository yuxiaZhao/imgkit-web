# 介绍

**imgpilot** 是一个纯前端图片处理工具库，提供链式 API 与函数式 API 两种调用风格。

## 设计目标

1. **纯前端**：核心算法不依赖任何运行时，浏览器端零原生依赖
2. **易用**：链式 API + 函数式 API 双风格
3. **可扩展**：纯函数核心层便于单测与二次开发
4. **可发布**：单 npm 包，含 `main` / `module` / `types` 三入口

## 适用场景

- 浏览器端图片预处理（上传前压缩/加水印）
- 静态站点/博客的图片批处理
- 教学与算法研究（核心层完全开源）

## 不适用场景

- 需要 GPU 加速的实时图像处理
- 专业图像编辑（PS 级别）
- 需要 EXIF 完整解析的场景
